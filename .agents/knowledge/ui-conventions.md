# UI 与本地化规范

## 视觉基线

- 使用 Windows 10 Settings 风格：克制的白/浅灰表面、清晰分隔线、紧凑信息密度和一致控件状态。
- 卡片、按钮、输入框和下拉框沿用 `App.xaml` 与现有资源，不为单一页面复制近似样式。
- 语言、管理模式/CLI 检测、创建工程编辑器选择等 ComboBox 必须使用同一 Win10 下拉框视觉与交互状态。
- 熟悉的操作优先使用项目已有图标资源；图标按钮需要可访问名称或 ToolTip。

## 布局约束

- 工程列表表头分隔线必须与内容列使用相同网格宽度。
- “版本”和“最后打开时间”的文本中心应位于相邻表头分隔线的几何中点。
- 修改列宽时同步修改表头与行模板，并在中文、英文下检查文字是否截断或覆盖。
- 控件应有稳定宽高或网格轨道，悬停、加载和动态文本不能推动整体布局。
- 不在卡片中嵌套卡片，不使用纯装饰渐变球或无意义大标题。

## 本地化

- 所有用户可见字符串进入 `Resources/Strings.en-US.json` 和 `Resources/Strings.zh-CN.json`。
- 两个资源文件保持相同 key 集；格式参数数量和顺序一致。
- 当前支持 `en-US` 与 `zh-CN`，切换语言后刷新导航、状态、列表模型派生文本和对话框。
- 读取中文文件时明确使用 UTF-8；终端乱码不等于源文件损坏。
- 设置页“关于”区域从程序集元数据读取版本和 `RepositoryUrl`；仓库地址显示为可点击链接，不在主窗口代码中复制版本信息。

## UI 验证

- 至少在默认窗口和窄窗口检查无重叠、截断和错位。
- 打开每个被修改的下拉框，检查默认、悬停、选中、禁用和弹出状态。
- 下拉菜单需要与主窗口一致的缩放淡入；列表和滚动页的滚轮使用像素级平滑过渡，并允许嵌套滚动区在边界继续传递。
- 切换中英文检查最长文本。
- 涉及列表时使用有数据、空数据、长路径和长版本字符串四种状态验证。
