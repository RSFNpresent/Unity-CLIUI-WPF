# 动画与窗口过渡规范

## 当前策略

- `SystemAnimationPolicy.CurrentPreference` 当前为 `FollowWindows`，统一读取 `SystemParameters.ClientAreaAnimation` 与 `MenuAnimation`。
- 仅当 Windows 的客户端区域动画和菜单动画都启用时播放界面动画；任一设置关闭时直接应用最终状态。
- 任何调用方只读取集中策略，不自行判断系统设置或增加第二个强制开关。
- 动画关闭时，所有预置为透明、缩小或偏移的元素必须立即恢复最终姿态；禁用过渡不得导致页面或导航保持不可见。

## 动画语言

- 参考 Win8/Win10 开始菜单：短距离滑入、淡入和轻微缩放，快速但不突兀。
- 快速操作约 180–220ms，普通页面进入约 280–360ms，亚克力揭示约 300ms。
- 只动画 `Opacity`、`TranslateTransform`、`ScaleTransform`，不动画布局尺寸、Margin 或大型 BlurEffect。
- 页面切换保持布局稳定，目标页显示后从右侧约 30px 淡入。
- 左侧导航按钮等待整窗首段出现后，从 78% 缩放、右侧约 26px 和 0% 不透明度按 64ms 间隔依次放大归位，形成 Win8 全屏开始菜单式磁贴层次。
- 导航选中的淡蓝背景和右侧强调线使用独立模板层；选中时从右侧滑入并淡入，取消选中时向左滑出并淡出，文字本身保持稳定。
- 首次显示必须在构造阶段预设隐藏姿态，并在 `ContentRendered` 后启动；普通页面切换排到下一次 Render，避免首帧布局吞掉动画。
- 飞入统一使用指数 EaseOut：前段快速移动，后段明显减速落位。
- ComboBox Popup 使用淡入、纵向展开和轻微位移；列表滚轮通过像素偏移在约 300ms 内平滑收敛。

## 窗口状态机

- `WindowTransitionController` 负责首次进入、最小化、最大化/还原、从最小化恢复和关闭。
- 最小化先执行退出动画再设置 `WindowState.Minimized`；恢复后重放进入动画。
- 最大化/还原直接切换到目标窗口状态并恢复最终内容姿态，不播放内容或亚克力遮罩动画，也不逐帧修改窗口 Bounds。
- 最小化保持 `Scale=1`，通过原生 HWND 坐标向下移动约 72px，并使用三次 `EaseIn` 加速离场；不得只移动 WPF 内容层。
- 从最小化恢复保持 `Scale=1`，将原生 HWND 从下方约 72px 向上移动归位并使用三次 `EaseOut` 减速，不得加入缩放。
- 最小化与恢复的亚克力遮罩水平偏移固定为 0，只允许内容沿垂直轴移动；22px 横向扫动仅用于其他需要该效果的窗口过渡。
- 关闭使用原生 HWND 整窗透明度在约 280ms 内淡出，不缩放、不移动；WPF 内容与 DWM 亚克力底板必须同步消失。动画期间继续拦截重复关闭，淡出完成后只放行一次真实 `Close()`；若其他处理器否决关闭，则恢复原始窗口样式和完全不透明状态。
- 控制器异步入口返回 `Task`，同步 WPF 事件使用 `Request*` 包装，内部记录并吞掉取消而非使用 `async void`。

## 亚克力过渡

- 原生 DWM 亚克力本身不做逐帧动画。
- DWM 亚克力底板不属于 WPF 视觉树；需要整窗平移时必须移动 HWND 坐标，让底板与内容同步，不能只动画 `WindowAnimationRoot.RenderTransform`。
- 整窗关闭不得只动画 WPF 根元素透明度。动画启用时，关闭前捕获已由 DWM 合成的完整窗口（含亚克力底板），用不激活、不显示任务栏的透明覆盖窗按应用动画策略淡出，同时隐藏原窗口，结束后再真实关闭。当前非透明 WPF `HwndSource` 不支持运行时强加 `WS_EX_LAYERED`，不得用 `SetLayeredWindowAttributes` 实现关闭淡出。
- `AcrylicTransitionMask` 不接收输入，只绘制标题栏和左侧导航；工作区、遮罩、标题/导航内容的层级固定为 `0 / 1 / 2`，使遮罩从透明表面后方显现且不会覆盖文字和按钮。先淡入背景遮罩，在完全覆盖时调用 `AcrylicWindow.SetEnabled`，再淡出遮罩。
- 激活状态请求采用最新状态优先：同状态重复请求直接忽略，反向请求立即取消当前遮罩动画和排队请求，停止切换焦点后只执行最后一次状态过渡。
- 初始原生亚克力启用后立即登记已应用状态，避免首次激活重复绘制遮罩。最小化动画接管遮罩并打断旧焦点请求；最大化/还原和关闭只取消旧请求，不启动新遮罩动画。
- 窗口状态遮罩使用冷灰蓝轻渐变，并在淡变时同步横向移动约 22px；最大化/还原从较高遮罩强度揭示，保证亚克力背景运动清晰可见，层级仍保持在所有文字与按钮之后。
- 激活窗口启用亚克力，失活窗口切换为不透明渐变；不支持亚克力时保持现有纯色回退。

## 验证

- Release 构建和策略回归测试必须通过。
- 启动后检查 input-idle 与响应状态；关闭动画最终必须退出进程。
- 人工检查导航、激活/失活、最小化、最大化、还原、关闭是否流畅且无闪烁、残留透明度或输入遮挡。
